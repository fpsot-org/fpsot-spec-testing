# Scope

This Working Group develops the FPSOT testing specification.

The specification covers how FPSOT projects test their software and their specifications: the test levels (unit, integration, contract, functional and end-to-end) and what each level may replace with a test double, the isolation and repeatability of unit and integration tests, behavior-driven development with Gherkin feature files in English and French and their parity, contract tests against published API descriptions, conformance suites for replaceable components and the claims a suite result supports, synthetic test data with reserved values and bilingual data, and how continuous integration runs tests, including required checks, flaky tests, coverage and tests of built artifacts. It includes an example feature file in each language and a script that checks feature files with a Gherkin parser.

It does not cover the choice of programming language, test runner or framework, security testing, accessibility testing, which the FPSOT accessibility specification covers, or performance targets.

Any changes of Scope are not retroactive.
